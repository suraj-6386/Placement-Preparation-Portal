3. ENVIRONMENT VARIABLE DETAILS
================================================================================

DATABASE_URL
  Purpose: Complete MySQL connection string for Aiven
  Format: mysql+pymysql://username:password@host:port/database?ssl-mode=REQUIRED&charset=utf8mb4
  When to use: Always use this for Aiven (Render production)
  Note: The driver must be mysql+pymysql (NOT mysql://)
        SSL mode is REQUIRED for Aiven security

DB_HOST
  Purpose: Database server hostname
  Value for Aiven: mysql-24602c0f-sg022529-6614.h.aivencloud.com
  Note: Only used if DATABASE_URL is not set

DB_PORT
  Purpose: Database server port
  Value for Aiven: 10844
  Note: Non-standard port; Aiven requires this
  Note: Only used if DATABASE_URL is not set

DB_USER
  Purpose: Database username for authentication
  Value for Aiven: avnadmin
  Note: Only used if DATABASE_URL is not set

DB_NAME
  Purpose: Database name/schema
  Value for Aiven: skillprep_db
  Note: Only used if DATABASE_URL is not set

DB_PASSWORD
  Purpose: Database user password
  Value for Aiven: <Your Aiven password>
  SECURITY: Do NOT commit this to version control
  Note: Only used if DATABASE_URL is not set

DB_SSL_ENABLED
  Purpose: Enable SSL/TLS for local databases
  Value for Aiven: false (SSL is configured in DATABASE_URL)
  Value for local MySQL: false (unless you enable SSL locally)


4. AIVEN SSL CONFIGURATION
================================================================================
Aiven requires SSL/TLS connections. The DATABASE_URL includes:

  ?ssl-mode=REQUIRED

This ensures:
- All connections to Aiven are encrypted
- No unencrypted data transmission
- Compliance with Aiven security requirements

The cryptography library (>=42.0.0) in requirements.txt handles SSL certificates.


5. CONNECTION PRIORITY (How the application chooses)
================================================================================
The application loads database settings in this order:

  1. If DATABASE_URL environment variable is set → Use it (Recommended for Aiven)
  2. If DATABASE_URL is empty → Build URL from individual parameters:
     DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME


RECOMMENDED APPROACH:
For Aiven on Render:
  - Set only DATABASE_URL
  - Leave DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME unset

For local development:
  - Set DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME
  - Leave DATABASE_URL unset


6. HOW TO SWITCH TO AIVEN (For Render Deployment)
================================================================================
Step 1: In Render environment variables, set:

  DATABASE_URL=mysql+pymysql://avnadmin:<PASSWORD>@mysql-24602c0f-sg022529-6614.h.aivencloud.com:10844/skillprep_db?ssl-mode=REQUIRED&charset=utf8mb4

Step 2: Replace <PASSWORD> with your actual Aiven password from the Aiven console.

Step 3: Do NOT set these environment variables on Render:
  - DB_HOST
  - DB_PORT
  - DB_USER
  - DB_PASSWORD
  - DB_NAME

Step 4: Deploy your application to Render. The application will use DATABASE_URL.

Step 5: Verify connection in Render logs:
  [OK] Connected to MySQL database 'skillprep_db'
  [OK] Database tables verified/initialized


7. HOW TO SWITCH BACK TO LOCAL MYSQL
================================================================================
To revert to your local MySQL development environment:

Step 1: In your .env file (or local environment), set:

  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_USER=online_mysql_user
  DB_PASSWORD=<your local MySQL password>
  DB_NAME=skillprep_db

Step 2: Do NOT set DATABASE_URL:
  (Leave it empty or remove it from .env)

Step 3: Ensure your local MySQL server is running:
  - Windows: Check MySQL service in Services
  - macOS: Check brew services list
  - Linux: Check systemctl status mysql

Step 4: Run your application locally:
  python app.py

Step 5: Verify connection in terminal output:
  [OK] Connected to MySQL database 'skillprep_db'
  [OK] Database tables verified/initialized

10. TROUBLESHOOTING
================================================================================

Connection refused on Render?
  → Verify DATABASE_URL is set correctly
  → Check Aiven password in DATABASE_URL
  → Ensure Aiven instance is running
  → Check Render logs for connection details

TypeError: Connection.__init__() got an unexpected keyword argument 'ssl-mode'?
  → This is now fixed in the updated configuration
  → The application automatically converts ssl-mode=REQUIRED to PyMySQL-compatible SSL options
  → No code changes needed; just ensure you're using the latest backend/config.py and backend/database.py
  → The SSL parameter is removed from the URL and passed via connect_args to create_engine()

Local MySQL connection after switching back?
  → Ensure local MySQL server is running
  → Verify DB_HOST=127.0.0.1 and DB_PORT=3306
  → Check local MySQL credentials in .env
  → Verify DATABASE_URL is NOT set

SSL certificate errors?
  → Aiven uses self-signed certificates; the application automatically skips verification
  → Ensure cryptography library (>=42.0.0) is installed
  → The application uses PyMySQL-compatible SSL options (check_hostname=False, verify_cert=False)
  → Verify Aiven instance status in Aiven console

12. FILES MODIFIED
================================================================================
backend/config.py
  - Added DB_SSL_ENABLED environment variable
  - Enhanced sync_database_url property with improved documentation
  - Now intelligently selects Aiven or local MySQL based on DATABASE_URL
  - Removes ssl-mode parameter from URL (PyMySQL doesn't support it in URL)
  - New method: get_database_ssl_options() returns PyMySQL-compatible SSL options

backend/database.py
  - Updated create_engine() call to use connect_args with SSL options
  - Automatically handles Aiven SSL requirements via get_database_ssl_options()
  - SSL is transparent; no password/credentials exposed

No other application files were modified. Existing functionality is preserved.

SSL IMPLEMENTATION DETAILS:
  - The DATABASE_URL may contain "ssl-mode=REQUIRED" for Aiven
  - The application removes this parameter (PyMySQL doesn't recognize it)
  - SSL options are passed via SQLAlchemy's connect_args parameter
  - For Aiven: Uses check_hostname=False and verify_cert=False (Aiven requirement)
  - For local MySQL: No SSL options added unless DB_SSL_ENABLED=true
